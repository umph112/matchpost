# 광고주 마이페이지(대시보드) — PC 버전 디자인 핸드오프

> **범위: 광고주 마이페이지(대시보드) PC 버전만.** 모바일·다른 페이지(캠페인/인플루언서/메시지/알림 상세)는 이번 대상 아님.
> 개발자가 **동작하는 뼈대 + 콘텐츠(더미 포함)** 를 잡아둠. Claude Design은 이 페이지의 **PC 대시보드 레이아웃·비주얼**을 완성.

## 무엇인가
- 광고주가 로그인 후 처음 보는 **홈(대시보드)**. 여러 캠페인·인플루언서를 관리하는 **PC 파워 대시보드**.
- 좌측 고정 사이드바(대시보드/캠페인/인플루언서/메시지/알림/정산) + 상단바(회사명·알림·로그아웃)는 이미 있음 → 비주얼 정리 대상.
- 코드: `src/app/(dashboard)/advertiser/dashboard/page.tsx` (데이터 쿼리·섹션 확인). 셸: `src/components/AdvertiserShell.tsx`.

## 마이페이지에 들어있는 요소 (데이터 준비됨)
1. **월 캘린더** — 이번달 내 캠페인(amber)·공개오픈(blue) 도트. (`HomeCalendar`)
2. **빠른 액션** — [＋캠페인 등록] · [🔍인플루언서 찾기]
3. **최근 캠페인 5개** (+전체보기 → /advertiser/campaigns) — 제목·상태배지(진행중/마감/완료/캔슬)·참여 N·확정 N·"딜시트 →"
4. **양식함** — 저장한 상세양식 목록 (없으면 예시 3개)
5. **친구등록 인플루언서** — 이름·카테고리·팔로워 (⚠️예시 4명, 기능 미구현이나 **최종 모양 기준으로 디자인**)
6. **대시·메시지** 미리보기 3 (상대·마지막메시지·미응답 뱃지)
7. **알림함** 미리보기 3 (아이콘·제목·읽음여부)
8. **집행 요약** — 확정 집행 예정액(원)

## 레이아웃 의도 (자유롭게 재배치 가능)
- PC 넓은 화면 → **위젯/카드 그리드형 대시보드**. 예시 배치:
  - 좌(넓게): 캘린더 · 최근 캠페인
  - 우: 집행요약 KPI · 빠른액션 · 메시지 · 알림 · 친구등록 · 양식함
- 한눈에 보이는 정보 밀도 + 스캔 용이성 중시. KPI 요약(캠페인 수/진행중/확정/집행예정)을 상단 카드 행으로 뽑는 것도 좋음.

## 제약·가이드
- Next 16 + Tailwind. 브랜드 액센트 amber(주황) 유지 or 제안.
- **PC 전용 디자인** (모바일 이번 제외). 셸 `<main>`에 `adv-pc` 클래스가 붙으므로, PC 스타일은 `[.adv-pc_&]:...` 또는 이 페이지 기준으로 잡으면 됨.
- 상태 색 관례: 확정=초록 / 협의중·진행중=amber / 마감=회색 / 캔슬=빨강.
- 데이터는 이미 내려옴 — 표/카드/위젯에 뿌리기만. 더미(예시 뱃지)는 실제 데이터 형태와 동일.
