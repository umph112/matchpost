# 광고주 데스크탑 — Claude Design 핸드오프

> 목적: 광고주(PC 파워유저)용 데스크탑 UX의 **세부 비주얼 디자인**을 Claude Design이 이어받기 위한 브리핑.
> 현재는 개발자가 **동작하는 뼈대(구조/라우팅)**만 잡아둔 상태. 데이터·흐름은 살아있고, **룩앤필/레이아웃 완성도**를 올리는 것이 디자인 몫.

## 제품 맥락
- 매치포스트 = 광고주 ↔ 인플루언서 **달력 기반 매칭 + 딜시트(캠페인 프로젝트 관리)**.
- **광고주 = PC 데스크탑(파워툴)**, 인플루언서 = 모바일 앱(추후). 둘은 같은 Supabase 데이터.
- 광고주 핵심 업무: 여러 캠페인 동시 운영 + **인플루언서별 조건·진행·게재·결제를 표로 관리(딜시트)**.
- 스택: Next.js 16(App Router) + Tailwind + Supabase. 브랜드 액센트 = amber(주황).

## 지금까지 만든 뼈대 (동작함)
- **셸**: `src/components/AdvertiserShell.tsx` — 좌측 고정 사이드바 + 상단바 + 넓은 콘텐츠(모바일 드로어). 반응형.
- **레이아웃**: `src/app/(dashboard)/advertiser/layout.tsx` — 모든 `/advertiser/*`를 셸로 감쌈. 회사명 표시.
- **사이드바 메뉴**: 대시보드 / 캠페인 / 인플루언서 / 메시지 / 알림 / (정산=곧).
- **PC ↔ 모바일 버전 선택 토글**: 상단바에 전환 버튼. 사용자가 직접 선택(localStorage `advViewMode`), 화면 크기와 무관. PC=사이드바+와이드, 모바일=앱형(사이드바 없음, 드로어). → 디자인 시 **두 모드 모두** 고려.
- **페이지(기존, 기능 동작)**:
  - `/advertiser/dashboard` — 개요(캘린더·내 캠페인·메시지·알림·집행요약). *아직 모바일 폭(max-w-lg) — 데스크탑 개편 필요.*
  - `/advertiser/campaigns` — 캠페인 목록(진행중/종료 탭) + 등록 버튼.
  - `/advertiser/campaigns/new` — 캠페인 등록 폼(항목 많음: 채널·구분·옵션·카테고리·미션·일정·장소·예산·수량·결제·상세·가이드). *데스크탑 2단 배치가 유리.*
  - `/advertiser/campaigns/[id]` — 캠페인 상세 = **딜시트 자리(아직 참여자 목록 수준)**.
  - `/advertiser/search`(인플루언서) · `/advertiser/messages` · `/advertiser/notifications`.

## PC/모바일 전환 메커니즘 (디자인 시 반드시 이해)
- `AdvertiserShell`이 **환경 자동 감지**(모바일 접속→모바일, PC→PC)로 기본 모드 결정. 사용자가 상단 토글로 바꾸면 localStorage(`advViewMode`)에 저장되어 우선.
- 모드가 콘텐츠에 전달되는 방식: 셸의 `<main>`에 **`adv-pc` 또는 `adv-mobile` 클래스**가 붙음. 페이지는 Tailwind 임의 변형 **`[.adv-pc_&]:...`** 으로 PC 전용 스타일 지정(예: `[.adv-pc_&]:max-w-none [.adv-pc_&]:columns-2`).
- 이미 적용된 예: 캠페인 등록 폼(PC=2단 멀티컬럼), 대시보드(PC=2단), 인플루언서 검색(PC=넓게). 디자인은 이 `[.adv-pc_&]:` 패턴으로 각 페이지 데스크탑 레이아웃을 잡으면 됨.

## 현재 대시보드 섹션 (더미데이터로 모양 채워둠)
- 캘린더 / 빠른액션(캠페인 등록·인플루언서 찾기) / **최근 캠페인 5개+전체보기** / **양식함(저장 상세양식, 없으면 예시)** / **친구등록 인플루언서(예시 4명, 기능 미구현)** / 대시·메시지 / 알림함 / 집행요약.
- ⚠️ "예시" 뱃지가 붙은 건 더미. 친구등록(즐겨찾기) 실제 기능은 추후(favorites 테이블+검색 버튼). 디자인은 **최종 모양 기준**으로 잡아도 됨.

## 디자인이 완성할 것 (우선순위)
1. **딜시트** (`campaigns/[id]`) — ⭐가장 중요. 인플루언서(행) × 항목(열: 채널/조건·페이/진행단계/게재URL/검수/결제) **표 중심 파워툴**. 상태 배지, 인라인 편집, 정렬·필터, 진행률(모집 N/M), 예산 대비 집행/잔여, 갭(미정) 하이라이트. 캠페인 상단엔 요약(일정·모집·예산).
2. **캠페인 등록 폼** — 데스크탑 2단/그룹 카드로 정리(현재 세로 1열). 섹션: 채널→구분→옵션→카테고리→제목→모집일정→진행일정(지역)→장소→예산→콘텐츠수량+미션→결제→상세+가이드.
3. **대시보드** — 데스크탑 개요(요약 KPI 카드 행 + 캘린더 + 캠페인 표 + 최근 활동). 현재 모바일 폭 → 와이드.
4. **사이드바/상단바** — 아이콘·타이포·활성 상태·회사 로고 영역 등 비주얼 정리.
5. 인플루언서 검색·메시지·알림 — 데스크탑 목록/2-pane.

## 디자인 제약·가이드
- Tailwind 유틸리티, 컴포넌트는 `src/components/`. 기존 amber 액센트 유지 or 제안.
- **반응형**: 데스크탑 우선이되 모바일에서 깨지지 않게(사이드바 드로어 이미 있음).
- 데이터는 이미 Supabase에서 내려옴 — 표/카드에 뿌리기만. (필드는 각 page.tsx의 쿼리 참조)
- 접근성/가독성(표 밀도, 상태 색: 확정=초록/협의중=amber/마감=회색/캔슬=빨강 톤 이미 사용).

## 참고 (설계 결정 배경)
- 딜시트 양면(광고주 콘솔 + 인플루언서 뷰), 모집~확정 루틴, 확정 토글/철회, 세무자료 교환, 미션 등은 프로젝트 메모리/`CLAUDE.md`에 정리돼 있음.
- 지도(장소)·공휴일 자동감지는 도메인/키 확보 후 별도 진행(현재 주소검색·주말감지까지).
