# D34 — 인플루언서 PC 구성 (B 부류)

원본: `매치포스트 인플루언서 마이페이지 PC.dc.html` (동봉)
대상: `inf-profile` · `inf-search` — 폭은 풀렸지만 **모바일 세로 배치가 늘어난** 화면입니다.

⚠️ **제가 앞서 「조건 왼쪽 320px / 결과 오른쪽」이라 한 것은 틀렸습니다.**
프로토타입은 필터를 **상단 전폭 카드**에 두고 그 안에서 2열로 가릅니다.
광고주 검색도 D11 §3 에서 284px 사이드바를 없애고 같은 방식으로 바꿨습니다 — 그것과 맞습니다.

---

# 1. `influencer/profile` → 「설정」 (탭 3개)

지금은 입력칸이 전부 1100px 로 늘어나 세로 1900px 로 쌓입니다.
전화번호 한 칸이 1100px 인 것이 모바일 폼을 늘린 증거입니다.

## 1-1. 머리 · 탭

```
h1 「설정」 23px/800 · letter-spacing:-0.03em
부제 「프로필과 채널, 정산 계좌, 크레딧을 관리합니다.」 13px · #7C7C88 · margin-top:5px
탭 줄 display:flex · gap:7px
```

**탭 3개** — 프로필 · 채널 / 정산 계좌 / 크레딧.
지금 한 화면에 다 있는 것을 셋으로 나눕니다. 그것만으로 세로 1900px 이 사라집니다.

## 1-2. 탭마다 그리드가 다릅니다

| 탭 | 그리드 |
| --- | --- |
| **프로필 · 채널** | `minmax(0,1fr) minmax(0,1fr)` · `gap:14px` · `align-items:stretch` |
| **정산 계좌** | `minmax(0,1fr) 320px` · `gap:14px` · `align-items:stretch` |
| **크레딧** | `300px minmax(0,1fr)` · `gap:14px` · `align-items:stretch` — **좌측이 검정 잔액 카드** |

⚠️ 탭마다 다른 이유가 있습니다 — 프로필은 두 덩어리가 대등하고, 정산은 계좌 목록이 주이고
안내가 보조, 크레딧은 잔액이 먼저 눈에 들어와야 합니다. 하나로 통일하지 마세요.

## 1-3. 카드 규격 (공통)

```
section  background:#fff · border:1px solid #EAEAEE · border-radius:14px
         overflow:hidden · display:flex · flex-direction:column
헤더     display:flex · align-items:center · padding:13px 20px
         border-bottom:1px solid #F1F1F4
  제목   13px/800
  우측   편집 링크 11.5px/700 · #B45309 (hover #92400E) · margin-left:auto
본문     padding:16px 20px
줄 구분  border-bottom:1px solid #F5F5F7
```

⚠️ **헤더 높이를 고정하지 마세요** — `padding` + `align-items:center` 로 상하 여백을 같게 줍니다
(프로젝트 규칙). 제목 아래 설명줄이 붙으면 고정 높이에서 위로 쏠립니다.

## 1-4. 프로필 · 채널 탭 안쪽

| 좌 | 우 |
| --- | --- |
| **기본 정보** — 아바타 + 활동명 · 실명 · 휴대폰 · 자기소개 | **채널** — 블로그 · 인스타 · 유튜브 · 틱톡 URL + 팔로워 수 |
| | **분야** — 메이저 1 + 서브 2 (칩) |

- 입력칸은 **카드 폭에 맞춥니다** (약 580px). 1100px 로 두지 마세요
- 짧은 값(휴대폰 · 팔로워 수)은 **카드 안에서 2열**로 — 한 줄 하나씩 쌓지 마세요
- 저장 버튼은 `SaveButton`(D31 [4]) 그대로

## 1-5. 아바타 · 별명

⚠️ 상단바의 별명·아바타는 여기 「기본 정보」와 **항상 같은 값**이어야 합니다
(아바타 = `initialOf(별명)`). 프로젝트 규칙입니다.

# 2. `influencer/search` → 「캠페인 검색」

지금은 「검색 조건」 카드가 폭을 통째로 먹고 그 안에서 날짜·키워드·버튼이 1100px 로 뻗습니다.
그리고 **결과 영역이 620px 비어 있습니다.**

## 2-1. 머리

```
h1 「캠페인 검색」 23px/800
부제 「날짜를 고르고 지역 · 분야로 좁혀 보세요. 기간 캠페인은 진행 기간 안의 모든 날짜에 나타납니다.」
     13px · #7C7C88 · 「날짜」만 700 · #3C3C46
```

부제가 **기간 캠페인 규칙**을 말해줍니다(D29 2절). 이게 없으면 「왜 9/7 에도 나오나」를 묻습니다.

## 2-2. 추천 (있을 때만)

```
grid-template-columns:1fr 1fr · gap:14px · align-items:stretch
```

추천이 0건이면 이 절을 렌더하지 마세요.

## 2-3. 검색 조건 — 상단 전폭 카드, 안에서 2열

```
카드    background:#fff · border:1px solid #EAEAEE · border-radius:14px
헤더    padding:13px 20px · border-bottom:1px solid #F1F1F4
  제목  「검색 조건」 13px/800
  옆    「비워두면 전체를 봅니다」 11.5px · #B0B0BB · margin-left:9px
본문    padding:16px 18px 18px
        display:grid · grid-template-columns:380px minmax(0,1fr) · gap:22px
        align-items:start
```

| 좌 380px | 우 나머지 |
| --- | --- |
| 지역 · 광고주 | 날짜 · 분야 · 키워드 · 검색 버튼 |

⚠️ **왼쪽 사이드바가 아닙니다.** 카드가 폭을 다 쓰고 그 **안에서만** 2열입니다.
사이드바로 만들면 결과가 좁아지고, 광고주 검색(D11 §3)과도 어긋납니다.

절 라벨: `11px/700 · #9A9AA5 · margin-bottom:7px`

## 2-4. 결과

```
카드 아래에 이어서. grid 로 2열 (minmax(0,1fr) 두 개 · gap:14px)
```

⚠️ **빈 상태를 반드시 그리세요.** 지금 620px 이 통째로 비어 있는 것이 가장 큰 문제입니다.

| 상태 | 무엇 |
| --- | --- |
| 검색 전 | 「날짜를 고르면 그날 진행하는 캠페인이 나와요」 + lucide 아이콘 |
| 결과 0건 | 「조건에 맞는 캠페인이 없어요」 + 「조건을 넓혀보세요」 |

빈 상태 카드는 `min-height:220px` · 가운데 정렬 · 문구 13px · `#9A9AA5`.

# 5. 확인

```bash
# 설정 탭
grep -n "sTabs\|정산 계좌\|크레딧" src/app/\(dashboard\)/influencer/profile/page.tsx

# 검색 필터가 카드 안 2열인지
grep -n "380px" src/app/\(dashboard\)/influencer/search/page.tsx

# 빈 상태
grep -n "날짜를 고르면\|조건에 맞는" src/app/\(dashboard\)/influencer/search/page.tsx
```

브라우저 (PC 1440px):
- [ ] 설정이 탭 3개로 갈리고, 세로 길이가 1900px 이 아님
- [ ] 프로필 탭이 2단 · 정산 계좌가 `1fr+320` · 크레딧이 `300+1fr`(좌측 검정)
- [ ] 입력칸이 카드 폭(약 580px) · 1100px 아님
- [ ] 휴대폰 · 팔로워 수가 카드 안에서 2열
- [ ] 검색 조건 카드가 폭을 다 쓰고 **그 안에서** 380px + 나머지
- [ ] 검색 전에 빈 상태 안내가 보임 (620px 공백 아님)
- [ ] 결과가 2열

브라우저 (모바일 390px):
- [ ] 두 화면 다 지금과 같음 — 세로 한 줄 · 가로 스크롤 없음
- [ ] 설정 탭은 모바일에서도 3개 (한 화면에 다 넣지 않음)
