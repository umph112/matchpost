## 1. 위치 — 팀 페이지 「공개 프로필」 절 안

```
src/app/(dashboard)/advertiser/team/page.tsx
```

이미 있는 「공개 프로필」 절에 **이어서** 넣으세요. 새 페이지를 만들지 마세요 —
마케팅 연락처와 같은 곳에 있어야 「인플루언서가 보는 화면」이 한 자리에서 관리됩니다.

배치 순서:
```
공개 프로필
  ├ 「회사 페이지 보기 →」               (이미 있음)
  ├ 마케팅 문의 연락처 공개 토글 + 미리보기 + 다른 연락처  (이미 있음)
  └ ── 구분선 ──
     한 줄 소개 · 소개 · 함께 일하는 브랜드 · 주요 이력   ← 이번에 추가
```

**대표만 보이는 절**입니다 (기존 게이트 그대로).

## 2. 필드 4개

전부 선택입니다. 비면 프로필에서 그 카드가 안 보입니다 — 그 사실을 화면에 적으세요.

| 순서 | 필드 | 입력 | placeholder |
| --- | --- | --- | --- |
| 1 | 한 줄 소개 | `input` height:46px | 비우면 소개의 첫 문장이 쓰여요 |
| 2 | 소개 | `textarea` min-height:110px | 어떤 일을 하는 곳인지 적어주세요. |
| 3 | 함께 일하는 브랜드 | `textarea` min-height:90px | 한 줄에 하나씩 적어주세요. |
| 4 | 주요 이력 | `textarea` min-height:110px | 한 줄에 하나씩 적어주세요. |

```
라벨   11.5px/700 · #3C3C46 + 「선택」 배지 (11px/700 · #B0B0BB)
입력   border:1px solid #E2E2E8 · border-radius:10px · padding:12px 13px (input 은 0 13px)
       font-size:12.5px · font-family:inherit · color:#17171B · outline:none
       textarea 는 resize:vertical
설명   11px · #7C7C88 · line-height:1.6 · margin-top:6px
필드 간 gap:14px
```

### 2-1. 한 줄 소개 — 기본값이 소개의 첫 문장

```
비었을 때 그 아래 회색 안내:
  「지금은 소개의 첫 문장이 쓰여요 — "{intro 첫 문장}"」
  11px · #9A9AA5

intro 도 비었으면:
  「소개를 적으면 첫 문장이 자동으로 쓰여요」
```

읽는 쪽(`[id]/page.tsx:110`)이 이미 `one_line ?? intro 첫 문장` 으로 되어 있습니다.
편집 화면이 그 규칙을 **말해주기만** 하면 됩니다. 로직을 새로 만들지 마세요.

### 2-2. 브랜드 · 이력 — 줄바꿈 그대로

읽는 쪽이 `whitespace-pre-wrap` 으로 렌더합니다(245 · 255행).
그래서 **줄바꿈을 그대로 저장**하면 됩니다. 파싱하지 마세요.

설명:
```
브랜드 「한 줄에 하나씩. 인플루언서가 "이 회사가 어떤 브랜드를 다루나"를 봅니다.」
이력   「한 줄에 하나씩. 예: 2025 성수 카페 오픈 캠페인 · 인플루언서 12명」
```

## 3. 저장

기존 `persistContact` 와 같은 방식 — **`onBlur` 로 그 필드만** 저장하세요.
저장 버튼을 만들지 마세요. 마케팅 연락처가 이미 그렇게 동작합니다.

```ts
persistProfile({ one_line: v.trim() || null })
```

빈 문자열은 `null` 로 저장합니다. 그러면 읽는 쪽의 `ap?.brands &&` 조건이 그대로 동작합니다.

## 4. 「직접 작성」 배지 — 읽는 쪽 확인

프로필 페이지의 소개 · 브랜드 · 이력 카드에 회색 「직접 작성」 배지가 있는지 확인하세요.
없으면 추가합니다.

```
10px/700 · background:#F1F1F4 · color:#7C7C88 · border-radius:4px · padding:2px 6px
```

**기록과 자기 어필이 섞이면 「매치포스트 기록」 4카드 전체를 못 믿게 됩니다.**
그 4카드에는 이 배지를 붙이지 마세요 — 대신 「매치포스트가 기록한 값이에요」가 있습니다.
