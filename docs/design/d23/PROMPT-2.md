```
사람이 직접 하던 테스트는 멈췄어. 가입 단계부터 막히니 봇으로 먼저 점검하자.

[순서] D28 을 먼저 고치고 그다음 봇이야. 순서를 바꾸지 마.
  D28 결함 4건 중 2번(PC 인플루언서 가입이 QR 게이트로 막힘)이 살아 있는 상태로 봇을 돌리면
  봇도 거기서 멈춰. 빈 QR 사각형 앞에서 할 게 없어.
  나머지 3건(입력 글자색 · 중복 입력 · 저장 후 무반응)도 봇이 「진행 불가」로 잡을 거라
  같은 것을 두 번 발견하게 돼.

  → docs/design/d28/PROMPT.md 부터 처리하고, 커밋한 뒤 봇으로 넘어가줘.

[봇 시나리오 — D23 문서 기준, 다만 순서를 바꿔줘]

  D23 이 협업 전 과정(대화 → 확정 → 검수 → 정산)이 중심인데,
  지금 막힌 곳은 그 앞이야. 가입·프로필 입력을 첫 시나리오로 올려줘:

  시나리오 0 — 가입 (새로 추가)
    0-1  PC 광고주 가입 3단계 완주 (사업자번호 검증 · 중복 차단 · 파일 첨부)
    0-2  PC 인플루언서 가입 완주   ← D28 2번을 고쳐야 가능
    0-3  모바일 인플루언서 가입 완주
    0-4  가입 직후 프로필 화면 — 가입에서 넣은 값이 채워져 있는지
    0-5  블로그 URL 저장 → 「채널 분석 보기」로 이어지는지
    0-6  초대 링크 가입 (/signup?invite=TOKEN)

  각 단계에서 확인할 것:
    · 입력한 글자가 읽히는지 (D28 1번)
    · 필수 항목을 비웠을 때 안내가 뜨는지
    · 버튼을 눌렀을 때 다음으로 가는지 → 아무 일도 안 일어나면 그게 결함이야
    · 같은 값을 두 번 입력하게 하지 않는지

  그 다음 D23 의 기존 시나리오(대화 → 확정 → 정산)를 이어줘.
```
